# Audio block specification

## Role

Audio represents music, dialogue, or sound design available to the Canvas.

## Color

The Audio block owns the accent color `#f59e0b`.

## Parent constraint

Audio is currently a top-level node. It has no child nodes.

## Properties

- Prompt

Audio asset IDs are internal metadata. They are generated automatically,
persisted with the Audio block, and are not shown in the edit panel.

Audio has a minimum size of 150x100 and a default size of 190x132. It has no
child gallery.
## Visual identity

Audio belongs to the Asset visual family and uses a waveform silhouette beside
its Prompt panel.
